Ontdek wat bij jou past.

Een AI-coach stelt je tien open vragen en vraagt door waar dat helpt. Er zijn geen goede of foute antwoorden.

    Goed om te weten
    De suggesties zijn een startpunt, geen definitief advies. Deel geen persoonlijke gegevens zoals je naam of adres.

    Jouw gesprek

    De coach is een taalmodel. Bij elk bericht gaat het hele gesprek via onze backend en een API naar het taalmodel, samen met de systeemprompt.

    Je antwoorden gaan via een API naar een taalmodel om een reactie te maken.
